# Gmail問い合わせフォームの設定

1. Apps Scriptプロジェクトに`Code.gs`の最新版を貼り付けて保存します。
2. **デプロイ > デプロイを管理**から既存のウェブアプリを編集し、新しいバージョンをデプロイします。
3. 初回はGmailとGoogleスプレッドシートへのアクセスを承認します。

フォームは`join.html`でウェブアプリURLを設定済みです。氏名・メールアドレス・電話番号・ご用件・お問い合わせ内容は必須で、お子様のお名前・年齢・学年・テニス歴・第2希望日時は任意です。体験レッスンとレンタルコートは第1希望日時も必須です。

レンタルコートのボタンからフォームへ進むと、ご用件が予約・空き状況に設定されます。送信内容は`informationozy@gmail.com`に通知され、Apps Scriptを実行するGoogleアカウントのドライブに「NOT TCお問い合わせ一覧」スプレッドシートが自動作成されます。メール通知は1日50件までですが、上限を超えた問い合わせもシートに記録されます。送信時点では予約確定ではなく、空き状況を確認後に連絡します。
